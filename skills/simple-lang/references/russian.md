# Russian reference: примеры и списки слов

Используйте этот файл вместе с `SKILL.md`. Здесь собраны примеры, списки слов и обоснования для русского текста. Полные тексты «было / стало» — в `passages.md`. Файл не добавляет и не меняет правила. Правила и лимиты — в `SKILL.md`.

## Содержание

1. Почему лимит слов для русского ниже
2. Примеры по директивам
3. Примеры R1–R5
4. Списки слов

---

## 1. Почему лимит слов для русского ниже

В русском нет артиклей, а падежи заменяют многие предлоги. Та же мысль занимает меньше слов. Поэтому лимиты слов для русского ниже английских. Значения — в таблице Hard limits в `SKILL.md`.

## 2. Примеры по директивам

### D1. Повелительное наклонение

| Плохо | Хорошо |
|---|---|
| Сервис должен быть запущен. | Запустите сервис. |
| Рекомендуется создать резервную копию. | Создайте резервную копию. |
| Необходимо убедиться в наличии доступа. | Убедитесь, что у вас есть доступ. |

### D2. Действительный залог

| Плохо | Хорошо |
|---|---|
| Файл должен быть создан пользователем. | Создайте файл. |
| Ошибка была зафиксирована системой мониторинга. | Мониторинг зафиксировал ошибку. |
| Настройки будут применены после перезапуска. | Сервис применит настройки после перезапуска. |
| Файл удаляется скриптом при каждом запуске. | Скрипт удаляет файл при каждом запуске. |

Пример исключения D2: «Пакет объявлен устаревшим в версии 3».

### D3. Глагол вместо отглагольного существительного

| Плохо | Хорошо |
|---|---|
| Выполните перезагрузку сервера. | Перезагрузите сервер. |
| Осуществляется отправка отчёта. | Скрипт отправляет отчёт. |
| Обеспечьте сохранение изменений. | Сохраните изменения. |
| осуществлять запуск | запускать |
| производить мониторинг | отслеживать |

Не маркер: «Выполните `DROP TABLE sessions;`». Здесь объект — команда, а не действие.

### D4. Одна мысль — одно предложение

| Плохо | Хорошо |
|---|---|
| Остановите сервис, очистите кэш и перезапустите сервер. | 1. Остановите сервис. 2. Очистите кэш. 3. Перезапустите сервер. |
| Сборка завершилась; артефакты лежат в `dist/`. | Сборка завершилась. Артефакты лежат в `dist/`. |

### D5. Условие — в начале

| Плохо | Хорошо |
|---|---|
| Данные будут потеряны при отсутствии резервной копии. | Если резервной копии нет, вы потеряете данные. |
| При наличии ошибок перезапустите сервис. | Если есть ошибки, перезапустите сервис. |
| При необходимости очистите кэш. | Необязательно: очистите кэш. |
| Запустите миграцию, но только на staging. | Если окружение — staging, запустите миграцию. Если нет, не запускайте её. |

Если автор знает условие, он его называет: «Если сборка падает с ошибкой кэша, очистите кэш».

### D6. Без воды, ответ первым

| Плохо | Хорошо |
|---|---|
| Просто откройте соответствующий файл конфигурации. | Откройте файл `config.yml`. |
| В конечном итоге этот подход позволяет добиться повышения производительности. | Подход ускоряет систему. |
| Существует два способа настроить прокси. | Настройте прокси одним из двух способов: |
| Отличный вопрос! Тайм-аут задан в config.yml, надеюсь, это поможет. | Файл `config.yml` задаёт тайм-аут. |

Сообщение от имени пользователя сохраняет приветствие: «Коллеги, привет! Мы переносим релиз на четверг».

### D7. Один термин — одно понятие

| Плохо | Хорошо |
|---|---|
| Запустите воркер. Когда процесс стартует, задача инициируется. | Запустите обработчик. Когда обработчик запустится, он запустит задачу. |
| Задайте RTO 4 ч. | Задайте целевое время восстановления (RTO) 4 ч. |
| резильентность | устойчивость |

Повтор термина — норма: «Сервис пишет логи. Сервис хранит логи 7 дней». Не заменяйте второе слово «сервис» на «данная система».

### D8. Факты, значения и форматы

| Плохо | Хорошо |
|---|---|
| значительно улучшен | задержка −35 % |
| надёжное решение | 0 сбоев на 10 000 запусков |
| время ответа 2.5 с | время ответа 2,5 с |
| 10000 запросов | 10 000 запросов |
| порт 50 051 | порт 50051 |
| 10/09/2026 | 9 октября 2026 г. или `2026-10-09` |

Копируйте значение из файла конфигурации как есть: `timeout: 2.5`.

### D9. Предупреждение до действия

| Плохо | Хорошо |
|---|---|
| Перезапустите сервис (сессии прервутся). | **ВНИМАНИЕ:** перезапуск прерывает активные сессии на 30 с. Предупредите дежурного. Затем перезапустите сервис. |

### D11. Сообщения об ошибках и интерфейс

| Плохо | Хорошо |
|---|---|
| Что-то пошло не так. Попробуйте позже. | Оплата не прошла: банк не ответил за 30 с. Повторите оплату. |
| Кнопки [ОК] [Отмена] в окне удаления | [Удалить] [Отмена] |

### D12. Модальность

| Черновик | Неверная правка | Верная правка |
|---|---|---|
| Сбой, вероятно, вызван ротацией сертификата. | Ротация сертификата вызвала сбой. | Ротация сертификата, вероятно, вызвала сбой. |
| Исправление должно убрать большую часть тайм-аутов. | Исправление убирает тайм-ауты. | Исправление, вероятно, уберёт большую часть тайм-аутов. |

## 3. Примеры R1–R5

### R1. Канцелярит

| Плохо | Хорошо |
|---|---|
| в целях реализации этой функции | чтобы реализовать эту функцию |
| на предмет наличия ошибок | нет ли ошибок |
| в рамках данного процесса | в этом процессе |
| Ускорьте сборку путём внесения изменений в файл конфигурации. | Измените файл конфигурации. Сборка ускорится. |
| имеет место задержка | запрос задерживается |
| Мониторинг является важным условием стабильности. | Мониторинг — условие стабильной работы. |

### R2. Цепочки родительного падежа

| Плохо | Хорошо |
|---|---|
| проверка конфигурации сервера баз данных пользователей | проверьте конфигурацию сервера с пользовательскими базами данных |
| журнал ошибок процесса обработки очереди сообщений | журнал ошибок при обработке очереди сообщений |
| план оптимизации скорости загрузки страниц сайта | план: ускорить загрузку страниц сайта |

Пример подсчёта: в «журнал ошибок сервера» после главного слова «журнал» стоят «ошибок» и «сервера».

Приёмы разрыва:

- Глагол вместо существительного (D3)
- Прилагательное: «базы данных пользователей» → «пользовательские базы данных»
- Предлог: «ошибок обработки очереди» → «ошибок при обработке очереди»
- Два предложения вместо одного

### R3. Прямой порядок слов

| Плохо | Хорошо |
|---|---|
| Временный файл при каждом запуске создаёт скрипт. | Скрипт при каждом запуске создаёт временный файл. |
| Для корректной работы сервиса требуется настроенный DNS. | Сервис требует настроенный DNS. |

У многих неодушевлённых существительных именительный и винительный падежи совпадают. Поэтому в «Файл создаёт скрипт» читатель примет «файл» за подлежащее.

### R4. Деепричастные и причастные обороты

| Плохо | Хорошо |
|---|---|
| Перезапустите сервер, предварительно сохранив логи. | Сохраните логи. Затем перезапустите сервер. |
| Нажмите «Сохранить», убедившись, что поля заполнены. | Убедитесь, что поля заполнены. Затем нажмите «Сохранить». |
| Запустив скрипт, создаётся файл. | Скрипт при запуске создаёт файл. |
| Падает сервис, обрабатывающий входящие запросы от внешних партнёров по API. | Сервис, который обрабатывает входящие запросы от внешних партнёров по API, падает. |

Пример к R4: в «журнал сервиса, который падает» непонятно, что падает.

### R5. Вид глагола и форма команды

| Плохо | Хорошо |
|---|---|
| Открывайте файл и найдите строку. | Откройте файл. Затем найдите строку. |
| Не откройте файл во время сборки. | Не открывайте файл во время сборки. |
| Не забывайте сохранять. (разовое напоминание) | Не забудьте сохранить. |
| Открыть файл. Проверьте строку. | Откройте файл. Затем проверьте строку. |
| Этот файл нельзя удалить. (имеется в виду запрет) | Не удаляйте этот файл. |

«Нельзя» + совершенный вид значит «невозможно»: «Файл нельзя удалить» — система не даст его удалить.

Сообщение коллеге на «ты» сохраняет «ты»: «Посмотри логи». Не меняйте его на «Посмотрите логи».

## 4. Списки слов

### Маркеры D3

Пустые глаголы в любом виде: «произвести», «осуществить», «выполнить», «провести», «обеспечить», «оказать», «совершить», «принять». Существительные со значением действия после них: «проверка», «запуск», «сохранение», «перезагрузка», «настройка», «анализ», «мониторинг», «отправка», «решение».

### Стоп-слова D6

Удалите: «как известно», «следует отметить», «стоит заметить», «в конечном итоге», «по сути», «собственно», «некий», «как видите», «надеюсь, это поможет», «давайте разберёмся».

Удалите усилители: «очень», «крайне», «максимально».

Если слово только усиливает или размывает смысл, удалите его:

- «достаточно» и «довольно» в значении «весьма»
- «просто» в значении «всего лишь»
- «определённый» в значении «некоторый»
- «соответствующий» без уточнения, чему он соответствует

Оставьте эти слова в прямом значении: «если места достаточно», «параметр, определённый в файле конфигурации».

Замените: «для того чтобы» → «чтобы», «в настоящее время» и «на сегодняшний день» → «сейчас».

### Словарь D7

| Понятие | Используйте | Не используйте |
|---|---|---|
| начать действие | запустить | стартовать, инициировать, осуществить запуск |
| проверить | проверить | верифицировать, проинспектировать, осуществить проверку |
| удалить | удалить | ликвидировать, зачистить, устранить (в значении «удалить») |
| использовать | использовать | задействовать, утилизировать (ложный друг: в русском значит «перерабатывать отходы») |
| показать | показать | отобразить, продемонстрировать |
| убедиться | убедиться | удостовериться, обеспечить уверенность |
